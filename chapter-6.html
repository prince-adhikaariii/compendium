Cyber Security, Encryption & Ethics

Malware taxonomy, Cryptography, 2FA/TOTP protocols, Digital Citizenship, and Ergonomic engineering.

Diagram 6.1: Multi-Layered Cyber Security Defense Infrastructure

6.1 Malware Taxonomy

Malicious Software (Malware) encompasses any unauthorized code designed to compromise system integrity:

  • Viruses: Code attached to host executable files that replicates across system drives when executed.
  • Worms: Standalone programs that actively self-replicate across network vulnerabilities without human execution.
  • Trojans: Malicious software masquerading as legitimate software (e.g., crack tools, fake utilities).
  • Ransomware: Cryptographic malware that encrypts files on a drive and demands payment for decryption keys.

6.2 Security Mechanisms: Encryption & 2FA

Data protection relies on mathematical cryptographic standards:

  • Symmetric Encryption: Uses a single secret key for encryption and decryption (e.g., AES-256). Fast and suited for bulk disk encryption.
  • Asymmetric Encryption: Uses a mathematically linked Key Pair (Public Key encrypts, Private Key decrypts). Used in RSA and ECC for web handshakes.
  • Two-Factor Authentication (2FA): Combines something you know (Password) with something you have (Time-based One-Time Password via Authenticator App).

6.3 Digital Ethics, Ergonomics & E-Waste

Responsible computing extends to physical safety, legal compliance, and environmental stewardship:

  • Plagiarism & Intellectual Property: Unauthorized reproduction of code, text, or creative media violates copyright laws. All sources must be cited.
  • Ergonomics: Engineering the workspace to prevent physical strain. Displays should sit at eye level, keyboards at elbow height, and breaks taken to avoid Repetitive Strain Injury (RSI).
  • E-Waste Management: Electronics contain hazardous heavy metals (lead, mercury, cadmium). E-waste must be routed to specialized recycling facilities to prevent toxic environmental leakage.

6.4 Social Engineering: Hacking the Human

Not all attacks target machines — many target people, tricking them into giving up sensitive information voluntarily:

  • Phishing: Fraudulent emails or messages pretending to be from a trusted source (like a bank), tricking victims into clicking malicious links or entering credentials.
  • Smishing / Vishing: The same trick performed via SMS text messages ("smishing") or phone calls ("vishing").
  • Pretexting: An attacker invents a false scenario ("I'm from IT support, I need your password to fix your account") to gain trust.
  • Shoulder Surfing: Simply watching someone type their PIN or password over their shoulder.

Golden rule: legitimate organizations will never ask for your password over email, SMS, or phone call.

6.5 Password Hygiene, VPNs & Backups

  • Strong Passwords: Should be long (12+ characters), mix upper/lowercase letters, numbers, and symbols, and never reused across multiple sites.
  • Password Managers: Software that securely generates and stores unique passwords for every account, so you only need to remember one master password.
  • VPN (Virtual Private Network): Encrypts your internet traffic and routes it through a secure remote server, hiding your activity from your local network — useful on public Wi-Fi.
  • Backups (3-2-1 Rule): Keep 3 copies of important data, on 2 different storage types (e.g., laptop + external drive), with 1 copy stored off-site or in the cloud — this protects against ransomware and hardware failure.
