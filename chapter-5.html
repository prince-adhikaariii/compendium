5.1 Fundamental & Universal Logic Gates

01 NOT Gate (Inverter)

The NOT Gate accepts a single binary input and produces its logical complement. If the input is 1, the output becomes 0, and vice versa.

Boolean Expression: $Y = \overline{A}$ or $Y = \neg A$

04 NAND Gate (Universal Gate)

A NAND Gate produces an output that is the inverse of an AND gate. It outputs 0 only when both inputs are 1. Because any Boolean function can be implemented using exclusively NAND gates, it is classified as a Universal Gate.

Boolean Expression: $Y = \overline{A \cdot B}$

05 NOR Gate (Universal Gate)

A NOR Gate produces an output that is the inverse of an OR gate. It outputs 1 only when both inputs are 0. Like NAND, it is a Universal Gate.

Boolean Expression: $Y = \overline{A + B}$

06 XOR & XNOR Gates

The XOR (Exclusive-OR) Gate outputs 1 if and only if the inputs are different ($Y = A \oplus B = A\overline{B} + \overline{A}B$). The XNOR Gate outputs 1 when the inputs are identical.

5.2 Combinational Logic: The Binary Half-Adder

Combining logic gates produces functional digital circuits. The Half-Adder takes two single binary inputs ($A$ and $B$) and calculates their arithmetic sum, generating a Sum ($S$) bit and a Carry ($C$) bit.

• Sum Bit Expression: $S = A \oplus B$ (XOR Gate)

• Carry Bit Expression: $C = A \cdot B$ (AND Gate)

5.2b From Half-Adder to Full-Adder

A Half-Adder can only add two single bits. To add binary numbers with many digits, we need a Full-Adder, which also accepts a Carry-In ($C_{in}$) from the previous column — just like carrying a "1" when adding multi-digit numbers by hand.

• Sum: $S = A \oplus B \oplus C_{in}$

• Carry-Out: $C_{out} = (A \cdot B) + (C_{in} \cdot (A \oplus B))$

Chaining eight Full-Adders together (a "Ripple-Carry Adder") is literally how a real CPU's ALU adds two 8-bit numbers.

5.2c Logic Gates in Everyday Life

  • AND example: A car only starts if the key is turned AND the seatbelt is fastened.
  • OR example: A room light turns on if switch A OR switch B (a two-way switch) is flipped up.
  • NOT example: A refrigerator light turns on when the door is NOT closed.

5.3 Systems Analysis: Data Flow Diagrams (DFDs)

A Data Flow Diagram (DFD) visually maps how data moves through an information system, detailing inputs, processing steps, storage locations, and outputs without describing hardware details.

Standard DFD Notation Symbols

1. External Entity (Square/Rectangle)

Represents external sources or destinations of data (e.g., Student, Bank API).

2. Process (Circle / Rounded Box)

Transforms incoming data flows into outgoing data flows (e.g., Calculate Grade).

3. Data Store (Open Rectangle)

Repositories where data is held at rest (e.g., Student Database, Logs).

4. Data Flow (Directed Arrow)

Indicates the direction of data movement between entities, processes, and stores.

DFD Hierarchy Levels

  • Context Diagram (Level 0): Abstract overview representing the entire system as a single process surrounded by external entities.
  • Level 1 DFD: Decomposes the single Level 0 process into major sub-processes and explicitly shows key data stores.
