4.1 Network Classifications & Topologies

Networks are categorized by geographic scale (LAN = local, MAN = city, WAN = global) and layout topology:

  • Star Topology: All devices connect to a central Switch/Hub. Failure of one cable does not crash the network, making it the modern standard.
  • Bus Topology: Single central coaxial backbone wire. Terminators are required at ends; prone to collisions.
  • Mesh Topology: Every node has redundant links to every other node, providing maximum fault tolerance for core infrastructure.

4.2 Addressing: IPv4 vs. IPv6

Every internet-connected device requires a unique logical address:

  • IPv4: 32-bit addresses written in dotted-decimal format (e.g., 192.168.1.100). Provides $2^{32} \approx 4.3$ billion addresses, leading to global exhaustion.
  • IPv6: 128-bit hexadecimal addressing (e.g., 2001:0db8:85a3::8a2e:0370:7334). Provides $2^{128}$ addresses, virtually eliminating address scarcity.

4.3 Web Navigation Flow: DNS & HTTPS

When typing https://example.com into a browser, the following sequential process occurs:

  1. DNS Lookup: Browser requests the Domain Name System (DNS) recursive resolver to resolve the human-readable domain into a numerical IP address.
  2. TCP 3-Way Handshake: Client and server exchange SYN, SYN-ACK, and ACK packets to establish a stable connection socket.
  3. TLS Handshake: Cryptographic keys are securely exchanged via HTTPS to establish an encrypted tunnel.
  4. HTTP GET Request: Client sends an encrypted HTTP request; the server responds with HTML/CSS data blocks.

4.4 Core Networking Hardware Devices

  • Modem (Modulator-Demodulator): Converts digital signals from your devices into analog signals suitable for phone/cable lines (and back), connecting your home network to the wider Internet Service Provider (ISP).
  • Router: Directs data packets between different networks, deciding the best path for traffic to travel from your device to the Internet and back — it also usually assigns local IP addresses via DHCP.
  • Switch: Connects multiple devices within the same local network (LAN), forwarding data only to the specific device it's addressed to (unlike a Hub, which broadcasts to everyone).
  • Access Point (AP): Extends a wired network to allow Wi-Fi (wireless) connections for laptops and phones.

DNS र HTTPS सुरक्षा:

• DNS (नेम सर्भर): जसरी फोनमा नाम थिच्दा अटोमेटिक फोन नम्बर डायल हुन्छ, त्यसै गरी DNS ले Domain (google.com) लाई IP Address (142.250.183.206) मा रूपान्तरण गर्छ।

• HTTP vs HTTPS: HTTPS मा प्रयोग हुने TLS Encrypted Shield ले बिचमा कसैलाई पनि (Hacker) तपाईंको पासवर्ड वा डाटा हेर्न दिँदैन।

• Router vs Switch: Router ले घरको इन्टरनेटलाई बाहिरी संसारसँग जोड्छ, जबकि Switch ले एउटै घर/स्कुल भित्रका धेरै कम्प्युटरहरूलाई आपसमा जोड्छ।
