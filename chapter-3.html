3.1 Positional Number Systems

Computers operate on binary physical states (high/low voltages represented as 1 and 0). Data interpretation depends on positional base mathematics where a digit at position n carries a weight of Basen.

Step-by-Step Conversion: Decimal to Binary (Successive Division)

To convert Decimal 25 to Binary, repeatedly divide by 2 and collect the remainders in reverse order:

25 ÷ 2 = 12, Remainder = 1 (LSB)

12 ÷ 2 = 6, Remainder = 0

6 ÷ 2 = 3, Remainder = 0

3 ÷ 2 = 1, Remainder = 1

1 ÷ 2 = 0, Remainder = 1 (MSB)

Result (Read bottom to top): 110012

3.2 Signed Integer Representation: 2's Complement

To represent negative numbers without requiring separate subtractive circuit hardware, CPUs use Two's Complement. To negate a binary number:

  1. Start with the positive binary value (e.g., +5 in 8-bit = 00000101).
  2. Invert all bits (1's Complement: 11111010).
  3. Add 1 to the LSB (2's Complement: 11111011 = -5).

3.3 Character Encoding Standards: ASCII vs. Unicode

Text values are represented using standard numeric encoding maps:

  • ASCII (American Standard Code for Information Interchange): 7-bit code mapping 128 standard English characters, control codes, and numbers (e.g., 'A' = 65 / 010000012).
  • Unicode (UTF-8 / UTF-16): Variable-width encoding supporting over 140,000 global characters, including Devanagari (Nepali script) and emojis, maintaining backward compatibility with ASCII.

3.4 Reading Binary: From Bits Back to Decimal

Going the other way, each binary digit (bit) is worth a power of 2 based on its position, counting from the right starting at 20:

Position Value1286432168421
Bit (110012)00011001

Add up the positions where there's a 1: 16 + 8 + 1 = 25. This confirms our earlier successive-division result — binary and decimal are just two ways of writing the same number.

3.5 Representing Fractions: Floating Point Numbers

Whole numbers use fixed-point binary, but real-world values like 3.14 or a bank balance of Rs. 1250.75 need decimals. Computers store these using the IEEE 754 Floating Point Standard, which splits a number into three parts inside a fixed number of bits (commonly 32 or 64):

  • Sign bit: 1 bit — indicates positive (0) or negative (1).
  • Exponent: Determines how far to shift the decimal (binary) point — similar to scientific notation.
  • Mantissa (Significand): Stores the actual significant digits of the number.

This is exactly why floating point math can sometimes show tiny rounding errors (e.g. 0.1 + 0.2 not being exactly 0.3 in some programming languages) — not every fraction can be perfectly represented in binary.

3.6 Worked Example: Encoding the Word "HI"

Using the ASCII table, every character maps to a fixed 7-bit decimal code:

'H'Decimal: 72
Binary: 01001000
'I'Decimal: 73
Binary: 01001001

So the text "HI" is really stored in memory as the byte sequence 01001000 01001001 — everything you type, every letter of Devanagari script, and every emoji ultimately becomes a string of bits like this.
