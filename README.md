# Computer Fundamentals Compendium 

A free, textbook-grade web portal teaching Computer Science fundamentals to Grade 8–10 students — built with interactive simulators, bilingual (English/Nepali) explanations, and structured diagrams to take students from basic concepts to near-advanced CS understanding.

This project started as a set of free CS fundamentals classes I taught at my father's old school, as a small thank-you for what that school gave him. It's built as a public, open web portal — not limited to that school alone, but free for any student or teacher, anywhere, to use.

##  Live Site

👉 **[Access the Computer Fundamentals Compendium](https://compendium.vercel.app)**

##  Contents

| Chapter | Topic |
|---|---|
| 1 | System Architecture — CPU cycles, ALU/CU, cache, buses, RAM/ROM, SSD vs HDD |
| 2 | Software & OS — Kernel functions, process scheduling, virtual memory, file systems, licensing |
| 3 | Data Representation — Number bases, 2's complement, floating point, ASCII/Unicode |
| 4 | Networks & Internet — OSI model, IPv4/IPv6, DNS, TLS/HTTPS, networking hardware |
| 5 | Logic Gates & System Modeling — Truth tables, simulators, combinational circuits, DFDs, algorithms |
| 6 | Cyber Security — Malware, cryptography, 2FA, social engineering, password hygiene |
| 7 | Operating Systems & System Software — Scheduling algorithms, system calls, device drivers |

Each chapter includes worked examples, interactive elements, diagrams, and a bilingual Nepali summary box for extra accessibility.

##  Tech Stack

- Plain HTML5 + vanilla JavaScript (no build step required)
- [Tailwind CSS](https://tailwindcss.com/) via CDN
- Google Fonts (Plus Jakarta Sans)
- Inline SVG diagrams

##  Running Locally

No installation needed — it's static HTML:

1. Clone the repo: `git clone https://github.com/prince-adhikaariii/compendium.git`
2. Open `index.html` directly in your browser, **or** serve it locally:
   ```bash
   python3 -m http.server 8000

   then visit http://localhost:8000

## Deployment

--This site deploys as a static project on Vercel (or Netlify / GitHub Pages):

--Push this repo to GitHub.

--Import it into Vercel → Framework Preset: Other → Build Command: (leave empty).

--Deploy — Vercel serves the HTML files directly and gives you a free *.vercel.app URL.
