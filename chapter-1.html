Computer Architecture & Hardware Mechanics

Von Neumann architecture, CPU fetch-decode-execute cycles, system buses, RAM/ROM dynamics, and storage physics.

1.1 What Exactly Is a Computer?

A computer is an electronic machine that takes in raw facts (Input), processes them according to a set of instructions (Processing), and produces meaningful results (Output) — while also being able to remember data for later (Storage). This is called the IPOS Cycle.

INPUTKeyboard, Mouse, Scanner, Mic
PROCESSCPU calculates & decides
OUTPUTMonitor, Printer, Speaker
STORAGESSD, HDD, Pen Drive

Think of it like cooking: raw vegetables (input) go to the cook (processor), who follows a recipe (program/instructions), and a finished dish (output) comes out — while some ingredients stay in the fridge for later use (storage).

1.2 The Fetch–Decode–Execute Cycle

Every single instruction a computer runs — from opening an app to adding two numbers — passes through the same three-stage cycle, repeated billions of times per second (measured in GHz, or billions of cycles per second):

  1. Fetch: The Control Unit (CU) retrieves the next instruction from RAM using the address stored in the Program Counter (PC), and loads it into the Instruction Register (IR).
  2. Decode: The CU translates the binary instruction into a set of electrical control signals — figuring out what operation to perform and which data it needs.
  3. Execute: The ALU (Arithmetic Logic Unit) actually performs the operation — an addition, comparison, or data move — and results are written back to a register or memory.

1.3 Memory Hierarchy: Registers, Cache, RAM & ROM

Not all memory is equal — computers use a layered hierarchy, trading off speed against size and cost:

Diagram 1.3: Fastest & smallest memory at the top, slowest & largest at the bottom

  • Registers: Tiny storage slots built directly inside the CPU, holding data currently being worked on. Fastest of all, but only a handful exist.
  • Cache (L1/L2/L3): A small, ultra-fast memory pool that stores frequently used data close to the CPU so it doesn't have to keep asking slower RAM.
  • RAM (Random Access Memory): Volatile memory — it holds running programs and data only while powered on, and is erased when the computer shuts down.
  • ROM (Read-Only Memory): Non-volatile memory that permanently stores the startup instructions (firmware/BIOS) needed to boot the computer, even without power.

1.4 Secondary Storage: HDD vs. SSD

Secondary storage keeps data permanently, even when the power is off, unlike RAM.

  • Hard Disk Drive (HDD): Uses spinning magnetic platters and a moving read/write head — mechanical, cheaper per gigabyte, but slower and more fragile due to moving parts.
  • Solid State Drive (SSD): Uses NAND flash memory chips with no moving parts — much faster, more durable, and energy-efficient, though historically more expensive per gigabyte.

Quick analogy: an HDD is like a record player needle physically moving across a vinyl disc; an SSD is like flipping a switch — instant, with nothing to move.

Bilingual Conceptual Summary (नेपाली)

CPU र Memory को सजिलो व्याख्या:

• CPU (सेन्ट्रल प्रोसेसिङ युनिट): यो कम्प्युटरको दिमाग हो। यसले Fetch (ल्याउने), Decode (बुझ्ने), र Execute (गर्ने) गरी हरेक निर्देशन पालना गर्छ।

• RAM vs ROM: RAM ले कम्प्युटर चलिरहेको बेला मात्र डाटा राख्छ (पावर निस्किए मेटिन्छ), तर ROM मा भएको डाटा पावर नभए पनि सधैं रहन्छ (जस्तै BIOS)।

• HDD vs SSD: HDD घुम्ने डिस्क भएको पुरानो, अलि ढिलो स्टोरेज हो; SSD मा घुम्ने पार्ट्स नभएकोले यो धेरै छिटो र बलियो हुन्छ।
