Operating Systems & System Software

Kernel architecture, process scheduling, virtual memory management, system calls, and device drivers.

7.1 The Role of the OS Kernel

The kernel operates at the core of any operating system, bridging the gap between application software and physical hardware resources. It manages process execution, memory allocation, and hardware device communication.

7.2 CPU Scheduling Algorithms

When multiple processes are "Ready" and waiting, the OS scheduler must decide which one runs next. Common algorithms include:

  • First-Come, First-Served (FCFS): Processes are executed strictly in the order they arrive — simple, but a long process can delay everyone behind it.
  • Shortest Job First (SJF): The process with the smallest estimated run-time is executed next, minimizing average waiting time.
  • Round Robin (RR): Every process gets a small fixed time slice (quantum) — e.g. 20 milliseconds — before being moved to the back of the queue, creating fair, responsive multitasking. This is what most desktop and phone OSes use.
  • Priority Scheduling: Each process is assigned a priority number; higher-priority processes (like playing audio) jump ahead of lower-priority background tasks.

7.3 Virtual Memory Management Recap

The kernel's Memory Manager gives each running program its own private virtual address space, translated to physical RAM addresses via page tables (see Chapter 2 for full details). This isolation is also a security feature — one buggy or malicious program cannot directly read or corrupt another program's memory.

7.4 System Calls & Device Drivers

Applications in User Space cannot touch hardware directly for safety reasons. Instead, they request kernel services through System Calls — standardized functions like open(), read(), or write(). The kernel then talks to hardware through Device Drivers: small pieces of software written specifically for each hardware component (a printer, graphics card, or Wi-Fi chip) that translate generic OS commands into device-specific instructions.
